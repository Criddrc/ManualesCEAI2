# Manual de Ingreso al Aplicativo GDC

Este documento describe el procedimiento general para ingresar al aplicativo GDC, desde el acceso inicial a la URL hasta la visualización de la interfaz principal.

---

## 1️⃣ Acceso a la URL
- Abrir un navegador web de preferencia.
- Ingresar la dirección del aplicativo:  
  **https://appsceai.com/gdc/public**

---

## 2️⃣ Ingreso de credenciales
- En la pantalla inicial se solicita autenticación.
- Introducir los datos requeridos:
  - **Usuario:** `nombre_usuario`
  - **Contraseña:** `contraseña`
- Confirmar el acceso presionando el botón correspondiente.

---

## 3️⃣ Modal de bienvenida
- Al ingresar, el aplicativo presenta un **modal de bienvenida**.
- Este modal indica el nombre del usuario autenticado y confirma el acceso al sistema.
- El mensaje mostrado es similar a:  
  *“Bienvenido(a) nombre_usuario al aplicativo para la carga de documentos”*.

---

## 4️⃣ Interfaz de entrada
Una vez cerrado el modal, se despliega la interfaz principal del aplicativo.  
Los elementos visibles incluyen:

- **Panel de usuario:** muestra el nombre completo del usuario autenticado.
- **Estado de documentos vigencia 2025:**
  - Documentos pendientes
  - Documentos entregados
  - Documentos aprobados
  - Documentos rechazados
- **Totales globales:** resumen general de documentos en cada estado.
- **Menú principal:** opciones como *Usuarios*, *Revisores*, *Vigencias*, *Reportes*, *Mis datos*.

---

## 5️⃣ Confirmación de acceso
- El usuario puede verificar que el acceso fue exitoso al visualizar:
  - Su nombre en la parte superior.
  - El conteo de documentos pendientes y entregados.
  - El menú de navegación habilitado.

---

## Nota
Este procedimiento es de carácter general y puede variar según la configuración específica del aplicativo o las actualizaciones realizadas por la entidad administradora.
