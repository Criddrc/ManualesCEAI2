# CREAR NUEVO PLAN DE MEJORAMIENTO

Este instructivo describe el procedimiento que debe seguir un instructor para crear un plan de mejoramiento

## 1️⃣ Acceder a la opción Planes de Mejoramiento

Con el rol de instructor acceda a la opción "Planes de Mejoramiento" del menú de Formación. En la interfaz que le presenta SAF, haga clic en el botón "Crear un nuevo plan de mejoramiento"
<figure markdown="span">
	![Image title](site:assets/imagenes/crear_pm/1_opcion_crear_plan.png)
</figure>


## 1️⃣ Seleccionar parámetros para el plan de mejoramiento

En la interfaz seleccione la ficha, el trimestre formativo, la guía y resultado de aprendizaje correspondientes para realizar el plan de mejoramiento. Tenga presente que el sistema sólo le mostrará las fichas, guías y resultados que usted tenga asociados.
En esta interfaz, usted debe indicar si el plan de mejoramiento está asociado a otro que el aprendiz no aprobó.  Esto aplicaría para realizar una recuperación a través de un segundo plan.
Si todos los parámetros están seleccionados haga clic en el botón SI para crear el plan de mejoramiento

## 2️⃣ Asociar a plan de mejoramiento anterior

Si usted desea asociar un plan de mejoramiento a otro, en la interfaz de creación marque la opción "Asociar a PM anterior". SAF le mostrará los planes de mejoramiento anteriores que algún aprendiz haya reprobado. Seleccione uno de la lista para establecer la relación

<figure markdown="span">
	![Image title](site:assets/imagenes/crear_pm/6_seleccionar_plan_anterior.png)
</figure>

Seleccione los aprendices que desea vincular con el plan de mejoramiento

<figure markdown="span">
	![Image title](site:assets/imagenes/crear_pm/7_seleccionar_aprendices_plan_anterior.png)
</figure>

Si todos los parámetros están seleccionados haga clic en el botón SI para crear el plan de mejoramiento
